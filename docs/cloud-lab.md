# Работа в облачной среде GitHub Codespaces

Этот репозиторий содержит настройку облачной среды Linux с Node.js 22. Виртуальную машину и контейнер подготавливает GitHub Codespaces. Установка VirtualBox, Node.js и скачивание ZIP на компьютер студента не требуются. Это среда с редактором, терминалом и работающим сервером; графический рабочий стол Windows в неё не входит.

## Начало работы

1. Войдите в свою учётную запись GitHub и откройте репозиторий.
2. Нажмите Code, выберите Codespaces и Create codespace on main.
3. Дождитесь завершения подготовки. Конфигурация автоматически запускает тесты и два экземпляра приложения.
4. Откройте вкладку Ports в нижней панели редактора. Порт 3000 — уязвимый стенд, порт 3001 — исправленный.
5. Нажмите значок открытия в браузере рядом с портом 3000. Войдите как student-a с паролем lab-a и выполните проверки из docs/assignment.md.
6. Для сравнения после исправления откройте порт 3001. Это отдельный сервер: войдите в него заново. Вместо перезапуска, описанного для локальной ВМ, переключайтесь между двумя вкладками.

## Автоматические проверки

В терминале Codespaces выполните:

```text
npm run test:policy:vulnerable > reports/before.txt 2>&1
npm run test:policy:fixed > reports/after.txt 2>&1
npm test
```

Ожидаются 3 провала до исправления, 0 после и 17 успешных тестов общего набора. Оба браузерных стенда продолжают работать во время проверки.

## Изоляция и сдача

У каждого студента должна быть собственная среда Codespaces и собственный отчёт. Не передавайте доступ к редактору преподавателя. По умолчанию адреса приложений закрыты для других пользователей. Преподаватель при необходимости может отдельно предоставить только доступ к веб-интерфейсу демонстрационного стенда.

В отчёте укажите GitHub Codespaces, Linux и версию Node.js. Снимок локальной настройки NAT для облачного варианта не требуется: вместо него приложите снимок редактора и вкладки Ports. Остальные ручные проверки, снимки и критерии оценки сохраняются.

## Завершение работы

После сохранения отчёта остановите свою среду в меню Codespaces. GitHub предоставляет личным аккаунтам ограниченную бесплатную квоту; работа и хранение расходуют её. Не подключайте оплату и не повышайте лимит расходов ради этого задания без отдельного решения владельца аккаунта. Публичный адрес демонстрационного стенда доступен только пока соответствующая среда запущена.
